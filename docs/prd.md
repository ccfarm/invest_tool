# 投资工具箱 — PRD

## 1. 概述

投资工具箱，当前包含三个模块：

- **股东查询**：输入股东姓名或 A 股代码，查看持股记录及变动情况
- **微盘股筛选**：按钮触发，选出最近完整交易日总市值最低的 30 只 A 股，排除 ST 及有 ST 风险的股票
- **趋势向上**：选出 MA20 连续 10 个交易日上行、换手率最低的 30 只 A 股，悬停代码可查看近 3 个月日 K 线

## 2. 目标用户

- 跟踪个股股东结构的投资者
- 关注个人/机构股东持仓变动的用户
- 关注小市值（微盘股）机会与风险的投资者
- 关注中期趋势（均线多头、低换手）机会的投资者

## 3. 股东查询

### 3.1 搜索

- 支持按**股东姓名**（模糊）或 **A 股代码**（精确）查询
- 空输入时点击查询：提示必填
- 无结果时展示空状态提示
- 同名股东、多账户等边界情况暂不做区分

### 3.2 持股记录列表

- 展示与该股东/股票相关的全部持股记录，按披露时间从新到旧排序
- 结果分页展示
- 表格列：A股代码、股票名称、股东名称、本期持股、披露时间、较上期变动
- 较上期变动：正数红色、负数绿色（A股红涨绿跌）、不变灰色、新进标记；数字千分位格式化

### 3.3 结果页操作

- 可在结果页继续修改关键词并重新查询
- 提供"清除"按钮一键清空输入

## 4. 微盘股筛选

### 4.1 触发与结果记录

- 页面提供"筛选微盘股"按钮，点击触发筛选逻辑
- 记录**最近一个完整交易日**的结果（交易日用新浪日K判定：有 K 线的日子即交易日，15:00 前未收盘则取上一交易日）
- 再次触发时先检查是否同一交易日：日期相同直接复用已有结果，不重复计算（返回 `reused` 标记）
- 每次触发的结果按交易日持久化到 SQLite（`microcap_snapshots`）
- 页面默认展示**最新一次**筛选结果

### 4.2 历史回看

- 下拉列表展示**近 20 次**触发日期（含触发时间）
- 选中某日期即可查看当天的筛选结果

### 4.3 筛选逻辑（设计要点）

1. **股票池**：全 A 股按总市值升序拉取，覆盖沪市主板、科创板、深市主板（含原中小板）、创业板，**不含北交所**；过滤无有效市值的股票（多为退市/PT 股）
2. **名称排除**：名称含 `ST` / `*ST` / `退` / `PT` 的股票直接排除，并写入黑名单
3. **ST 风险评估（公告排查）**：对市值最低的候选池（默认前 100 只）逐只拉取最近公告标题，命中风险关键词（退市风险警示、其他风险警示、被立案调查、无法表示意见、保留意见、存在退市风险、终止上市、退市整理、净资产为负、连续亏损、扣非净利润为负、股价低于面值、面值退市、重大违法等）即视为有 ST 风险，排除并写入黑名单
4. **黑名单**：被排除的股票加入 `microcap_blacklist`（含排除原因），**永久生效**，后续筛选不再重复判断
5. **结果**：剩余股票按总市值升序取**最低 30 只**

> 完整设计说明已写入代码注释（`backend/app/microcap.py` 模块头部）。

## 5. 趋势向上

### 5.1 触发与结果记录

- 页面提供"刷新"按钮，点击触发筛选逻辑
- 记录**最近一个完整交易日**的结果（交易日判定与微盘股一致：新浪日 K，15:00 前未收盘则取上一交易日）
- 再次触发时先检查是否同一交易日：日期相同直接复用已有结果，不重复计算（返回 `reused` 标记）
- 每次触发的结果按交易日持久化到 SQLite（`trend_snapshots`），页面默认展示最新一次

### 5.2 历史回看

- 下拉列表展示**近 20 次**触发日期（含触发时间）
- 选中某日期即可查看当天的筛选结果

### 5.3 筛选逻辑（设计要点）

1. **股票池**：全 A 股按**换手率升序**拉取（东方财富行情接口，字段 f8），
   覆盖沪市主板、科创板、深市主板（含原中小板）、创业板，**不含北交所**
2. **基础过滤**：无有效现价/换手率（停牌、退市、PT）或换手率 ≤ 0 的跳过；
   名称含 `ST` / `*ST` / `退` / `PT` 的跳过
3. **MA20 上行判定**：逐只拉取最近约 3 个月日 K（新浪），要求
   `MA20(t-10) < MA20(t-9) < ... < MA20(t)`（严格逐日递增，天数可配置 `TREND_UP_DAYS`）
4. **结果**：因为股票列表已按换手率升序，按扫描顺序取**前 30 只通过**的股票
   即为"换手率最低的 30 只"；命中即停止拉取 K 线，减少请求量

### 5.4 悬停 K 线

- 表格"代码"悬停时展示近 3 个月日 K 线（含 MA20 曲线，红涨绿跌）
- K 线数据来自后端 `GET /api/trend/kline`，后端内存缓存（默认 5 分钟），
  筛选时顺手预热入选股票的 K 线，首次悬停无需再次请求行情接口

> 完整设计说明已写入代码注释（`backend/app/trend.py` 模块头部）。

## 6. 页面结构

### 6.1 搜索页（/）

- 顶部导航：工具箱标识、工具入口（股东查询、微盘股）、明暗主题切换
- 搜索表单 + 空状态引导文案

### 6.2 结果页（/results）

- 复用搜索表单，输入框预填查询词
- 结果汇总（记录总数）+ 持股记录表格

### 6.3 微盘股页（/microcap）

- 筛选按钮 + 历史日期下拉
- 结果表格：排名、代码、名称、总市值
- 触发提示（新筛选 / 同交易日复用 / 新增黑名单数量）

### 6.4 趋势向上页（/trend）

- 刷新按钮 + 历史日期下拉
- 结果表格：排名、代码、名称、现价、换手率、MA20
- 代码悬停展示近 3 个月 K 线（含 MA20），点击跳转股东查询

## 7. 非功能要求

- 支持明暗主题切换
- 响应式布局，适配移动端
- 表格数字使用等宽数字（tabular-nums），便于对齐
- 页面底部展示 PV 统计（今日/累计，持久化到 SQLite）

## 8. 数据

- 股东数据：项目自带爬虫，数据源为东方财富数据中心（十大股东公开数据），全 A 股（沪深北 5000+ 只）每日增量更新；服务启动时自动后台执行增量检查，之后每 24 小时一次，断点续传
- 微盘股数据：股票列表与总市值来自东方财富行情接口，交易日历来自新浪日K，公告排查来自东方财富公告接口
- 趋势向上数据：股票列表与换手率来自东方财富行情接口，日 K 与交易日历来自新浪日K

## 9. 技术方案

- 前端：Vue 3（单页应用，路由：`/` 搜索页、`/results` 结果页、`/microcap` 微盘股页、`/trend` 趋势向上页）
- 后端：Python + FastAPI，单服务提供 API 并托管前端构建产物
- 存储：SQLite（持股数据、爬虫断点、PV 统计、微盘股快照与黑名单、趋势向上快照）
- 尽量简单：不引入复杂状态管理，暂不做鉴权
